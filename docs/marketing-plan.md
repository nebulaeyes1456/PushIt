# PushIt · 多平台宣传方案

> 依据：项目书 §14 冷启动与分发（不买量、内容先行、合规叙事）。
> 配套：docs/distribution.md（获取链路）、data/research_v2ex.json（需求证据）。

## 0. 定位与合规口径（所有平台统一）
- 叙事 = **"数据化向上管理 / 职场沟通效率工具"**；**注意：知乎调研显示年轻人反感「向上管理」这个词（觉得像讨好领导）——宣传文案禁用该词**，改用「把账算清 / 让不合理需求现形 / 不会还价」；
- 禁用"对抗领导 / 教人怼领导"措辞（§9 审核合规）；
- 分享一律**去标识化**（不出现真人名/公司名）；低调品牌：副标用"排期 · 需求小账本"；
- 测试期话术：所有帖子标注 **"测试中（alpha），欢迎反馈"**，降低预期也积累种子用户。

## 0.5 现成 Slogan（知乎高赞原文，标注出处）
> "学会对不合理的需求说'不'，比会加班重要一百倍。" —— 知乎《关于项目范围蔓延的一个感悟》

- 局限：微博/小红书需登录+签名风控，未抓（合规边界）；补充方式=截图/粘贴内容给我归类。

## 2. 平台矩阵与打法（按优先级）

| 平台 | 目标人群 | 内容形式 | 标题示例 | 合规/风险注意 |
|---|---|---|---|---|
| **V2EX**（种子首选） | 程序员，痛感最痛 | 求助帖/经验帖（正文贴话术案例） | "领导一句话加活，你们怎么回才不伤感情？" | 社区反感硬广：只发真实案例，链接放签名/文末 |
| **掘金 / CSDN** | 工程师 | 技术叙事文（"我用一个账本治好了需求蔓延"） | 同上 | 内容平台，重质量不重促销 |
| **知乎** | 泛知识工作者 | ① 直接回答「有哪些比较好用的职场工具」类问题导流；② 用高赞问题标题当回答素材 | 标题如：「如何聪明地拒绝领导（147赞）」「我直接怼回去了，是我太冲动了吗」 | 已有竞品软文在知乎占位，尽早写回答；避免自问自答刷屏 |
| **小红书** | 年轻职场人 | 图文笔记（话术卡片截图+使用前后对比） | "被领导临时加活，别再硬扛了" | 女性向内容友好；忌渲染职场对立 |
| **B站 / 抖音** | 泛职场 | 1-2 分钟演示视频（"把领导的加活贴进去会发生什么"） | 演示流，真人出镜或录屏 | 需出镜/配音成本，放量期再做 |
| **微信公众号** | 私域沉淀 | 周更案例复盘（真实交锋记录+话术拆解） | 用于留存与传播素材 | 测试期可不做，验证后再开 |
| **微博** | 泛讨论 | 高共鸣短帖+截图 | "被临时加活是一种什么体验" | 热点敏感，用中性词 |

## 3. 内容模板（四类，轮换使用）
1. **求助帖**："领导一句话加活，怎么拒绝不穿小鞋？"（引发共鸣→收集反馈→文末工具）；
2. **经验帖**："我靠一个账本治好了领导的随手加活"（讲真实使用过程+赢回时间数据）；
3. **案例帖**（去标识化）："上周挡掉 3 件活、保住了演示会，我是这么说的"（贴话术卡）；
4. **对比帖**："同样一句拒绝，说错 vs 说对的差别"（红线检测器演示）。

> 每篇结尾统一放落地链接（电脑版 Release + 手机版网址）+ "测试中，欢迎反馈"。

## 4. 冷启动节奏
- **第 1 周（种子期）**：V2EX + 知乎各发 1 篇求助帖；邀请 10 位真实用户试用（对照 §12 访谈），收集"首条记录 ≤5 分钟"完成率；
- **第 2 周（复盘期）**：根据反馈改体验（Day 0 引导、话术质量）；发第 2 篇经验帖；
- **第 3-4 周（放量期）**：小红书图文 + B站演示视频；启用"分享卡片"做 UGC 裂变；
- **持续**：把用户真实交锋（脱敏）沉淀为周更案例，形成内容复利。

## 5. KPI 与反馈闭环（对应 §12.1）
- 北极星：周活跃"交锋/留痕"次数；护栏：首条记录完成率、3 周留存、"关系未恶化"自评、分享率 K、转嫁集中度；
- 每条帖子埋 UTM 追踪来源；每周对照"痛点命中分布 vs 产品使用分布"修正内容方向。
