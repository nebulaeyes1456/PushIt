# PushIt · 发布与分发指南

> 回答一个问题：**论坛用户看到推荐后，如何拿到并用起来？**
> 现状：软件功能已可用（M2 完成）；"获取链路"尚未上线。本指南给出零成本上线路径。

## 一、上线三件套（全部免费起步）

### 1. 电脑版 → GitHub Releases（或网盘）
- 建公开仓库（如 `github.com/<你>/PushIt`），把 `release/PushIt-电脑版-安装包.zip` 传到 Releases；
- 得到永久下载链接：`https://github.com/<你>/PushIt/releases/latest`；
- 注意事项：exe 未做代码签名，Windows SmartScreen 会提示"更多信息 → 仍要运行"，
  教程与帖子里**提前说明**，降低用户疑虑；后续有余力再买代码签名证书。

### 2. 手机版 → 免费静态托管（PWA）
- `frontend/` 是纯静态应用（已含 manifest + Service Worker，离线可用）；
- 推送到 GitHub 后开 Pages，或 Vercel / Cloudflare Pages 直接托管该目录；
- 手机浏览器打开网址 →「添加到主屏幕」→ 桌面上得到 PushIt App（全屏、有图标）；
- **规则模式完整可用、数据存手机本地、零成本**；DeepSeek 增强需后端（见 3）。

### 3. 后端 → 可选（要 AI 增强时再上）
- 轻量部署 `backend/`（VPS / Render / Railway），环境变量 `PUSHIT_DATA_DIR` 指向可写目录；
- 前端"我 → 后端地址"可配置，填公网地址即可（界面已支持，保存后刷新生效）；
- 暂不上后端时，手机/网页版用规则模式，体验已完整。

## 二、用户旅程（获客到首用）
```
论坛/帖子看到 → 点链接
  ├─ 电脑用户：下载 zip → 解压 → 双击 PushIt.exe → 浏览器自动打开（≤1 分钟可用）
  └─ 手机用户：点网页链接 → 立即打开使用 → 添加到主屏幕（≈30 秒）
首用引导（Day 0 ≤5 分钟）：贴一条加活 → 生成报告 → 挡掉/对齐 → 得到即时正反馈
传播：话术卡「生成分享卡片」→ 去标识化文本 → 用户自发发帖 → 新用户回流
```

## 三、帖子/宣传文案模板（可直接用，落地链接自行替换）
```
【模板 A · 求助帖】"领导一句话加活，怎么拒绝不穿小鞋？"
正文：最近被领导一句话加了三件事……试了个小工具，把加活贴进去，
它会算代价账、给一段能直接念的话术，还帮你留痕防背锅。
电脑：{电脑版下载链接}  手机：{网页链接}（打开即用，可加到主屏幕）

【模板 B · 经验帖】"我靠一个账本治好了领导的随手加活"
正文：核心不是怼回去，是把账算清楚 + 书面留痕。附工具 {链接}
（分享卡片功能可一键生成类似内容）
```
> 合规口径：宣传叙事一律用"向上管理 / 职场沟通效率工具"，不用"对抗领导"措辞（§9/§14）。

## 四、发布检查单（每次发版照抄执行）
- [ ] 跑测试：`.venv/Scripts/python -m unittest discover -s tests`
- [ ] 浏览器验收：`python -m http.server 8123 --directory frontend` 后走一遍主流程
- [ ] 重打包 exe（frontend 有改动时必打）：见 README「打包」命令
- [ ] 上传 GitHub Release + 更新 Pages（静态前端）
- [ ] 帖子文案替换落地链接 → 发帖
- [ ] 版本号与《更新日志.md》同步（沿用既往纪律）
